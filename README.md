# Elegant Notes

A beautiful, responsive note-taking web application with a clean and modern design. Store your thoughts and ideas in style with an intuitive interface that works seamlessly across all devices.

## 🌐 Live Demo

Try the application online: [https://yofukashiya.github.io/NoteApp/](https://yofukashiya.github.io/NoteApp/)

## ✨ Features

-   **📝 Create & Manage Notes**: Add, view, and delete notes with ease
-   **🏷️ Tag System**: Organize notes with four categories:
    -   Work (💼)
    -   Personal (👤)
    -   Ideas (💡)
    -   Reminders (🔔)
-   **🔍 Search & Filter**: Find notes quickly with real-time search and category filtering
-   **🌙 Dark/Light Theme**: Toggle between light and dark modes with persistent preference
-   **💾 Local Storage**: All notes are saved locally in your browser
-   **📱 Responsive Design**: Works perfectly on desktop, tablet, and mobile devices
-   **🎨 Modern UI**: Clean, elegant interface with smooth animations and hover effects

## 🚀 Getting Started

### Prerequisites

-   A modern web browser (Chrome, Firefox, Safari, Edge)
-   No additional software or dependencies required

### Installation

1. Clone the repository:

    ```bash
    git clone https://github.com/yofukashiya/NoteApp.git
    ```

2. Navigate to the project directory:

    ```bash
    cd NoteApp
    ```

3. Open `index.html` in your web browser:
    - Double-click the file, or
    - Right-click and select "Open with" your preferred browser

That's it! The application will run locally in your browser.

## 🎯 How to Use

1. **Adding a Note**:

    - Click the "Add" button
    - Enter a title and content
    - Select a tag category
    - Click "Save Note"

2. **Searching Notes**:

    - Use the search bar to find notes by title or content
    - Search is case-insensitive and updates in real-time

3. **Filtering Notes**:

    - Use the dropdown to filter by category
    - Combine with search for precise results

4. **Deleting Notes**:

    - Click the trash icon on any note
    - Confirm deletion in the popup dialog

5. **Theme Toggle**:
    - Click the moon/sun icon to switch between light and dark themes
    - Your preference is automatically saved

## 🎨 Design Features

-   **Responsive Grid Layout**: Adapts from 1 column on mobile to 3 columns on desktop
-   **Smooth Animations**: Fade-in effects and hover transitions
-   **Color-coded Tags**: Each category has its own distinct color scheme
-   **Modal Dialogs**: Clean popup interfaces for adding notes and confirmations
-   **Empty State**: Helpful message when no notes are present
